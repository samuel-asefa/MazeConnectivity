# Source notes

This repository contains class code, coursework, and prior study solutions for maze connectivity in java. It is one independent topic project from the recovered Data Structures materials.

## Working-copy changes

The four completed node-mapping/union/reachability methods were restored from the submitted answer sheet. The working main method accepts a filename and node-pair queries. The original maze starter is preserved. Two supporting Union Find files are included locally; no sibling repository is required. The diagonal example was added for the assigned movement check.

## Organization

Source and sample input bytes were copied from the previously verified working collection. Source files are now directly under `src/`. Each repository has its own source list, README, original snapshots, and a topic-specific runner assembled from the existing regression checks. No algorithm changes were made during this split.

Build output and compiled classes are excluded from the package. Original snapshots are not compiled, because they can contain unfinished code or duplicate class names.
